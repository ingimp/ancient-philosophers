# Copertina del volume

Per ora **non è stata scelta alcuna immagine di copertina**. La compilazione `completa` impiega una copertina tipografica **provvisoria**.

Inserire in questa cartella:

- `prima.pdf`: copertina illustrata anteriore, A4 verticale, 1 pagina;
- `quarta.pdf`: facoltativa, quarta di copertina A4 verticale, 1 pagina.

Il PDF `completa` le includerà automaticamente, senza modificare i capitoli o il frontespizio interno.
